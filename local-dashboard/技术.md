# 本地看板 / 仪表盘 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 服务 | Node / Express（零依赖亦可） | 本地 API |
| 前端 | 原生 / React | 轻量 |
| 图表 | ECharts / Chart.js | 可视化 |
| 存储 | 本地 JSON / SQLite | 纯本地 |
| 布局 | 卡片网格 | 可配置 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **信息架构**：概览 + 分区 + 小部件
- **数据契约**：API 返回结构
- **实时刷新**：轮询 / SSE
- **本地优先**：数据不出本机

## 学习路径

1. 先做静态布局
2. 再接本地 API 取数
3. 最后加图表与实时刷新
