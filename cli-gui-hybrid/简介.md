# CLI + GUI 混合工具 · 简介

> 同时提供命令行与图形界面的混合工具

## 能做什么

- 命令行批处理
- 图形界面操作
- 配置共享
- 脚本化调用
- 进度可视化

## 适合的项目

- **开发者工具**：双入口
- **运维工具**：批处理 + 可视化
- **内部工具**：兼顾两类用户

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Node / Python、commander / click、Electron / Gradio / PySide
- 注意：同一内核双入口，脚本与人工都能用

## 快速开始

```bash
node cli.mjs --help
python app.py   # GUI 模式
# 也可 --headless 批处理
```
