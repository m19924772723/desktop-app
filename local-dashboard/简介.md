# 本地看板 / 仪表盘 · 简介

> 本地数据看板与仪表盘（个人工作台类）

## 能做什么

- 数据聚合展示
- 图表与小部件
- 实时刷新
- 深浅主题
- 卡片式可配置布局

## 适合的项目

- **个人工作台**：记录与统计
- **运营看板**：指标监控
- **本地数据仪表**：可视化

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Node + 原生前端 / Express、ECharts / Chart.js、本地 JSON / SQLite
- 注意：本机已有「个人工作台」可作参考实现

## 快速开始

```bash
node server.mjs
# 浏览器打开 http://127.0.0.1:PORT
curl http://127.0.0.1:PORT/api/state
```
