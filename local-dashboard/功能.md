# 本地看板 / 仪表盘 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 数据

- **聚合展示**：多源汇总
- **卡片小部件**：模块化
- **筛选搜索**：快速定位

## 图表

- **趋势 / 分布**：常见图型
- **统计卡**：关键指标
- **可交互**：悬浮提示

## 布局

- **卡片网格**：响应式
- **主题**：深浅可切
- **可配置**：增删模块

## 交互

- **实时刷新**：轮询 / SSE
- **导出**：CSV / 报告
- **键盘操作**：快捷键

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
