# 笔记 / 知识管理桌面端 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 存储 | Markdown 文件 | 可被 Obsidian 打开 |
| 检索 | 中文全文检索 | 二元切分 / FTS |
| 链接 | 双链 / 反链 | 知识网络 |
| 图谱 | 力导向图 | 结构可视 |
| 界面 | Electron / Web | 编辑体验 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **文件即数据库**：Markdown 为骨
- **双链**：[[链接]] 与反链
- **中文检索**：分词与索引
- **图谱**：节点与关系可视化

## 学习路径

1. 先做 Markdown 编辑与预览
2. 再加双链与检索
3. 最后做图谱与导出
