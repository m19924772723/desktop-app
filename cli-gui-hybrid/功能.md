# CLI + GUI 混合工具 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## CLI

- **子命令**：功能分组
- **批处理**：无界面运行
- **脚本化**：可被调用

## GUI

- **表单操作**：可视化配置
- **进度显示**：实时反馈
- **结果展示**：预览

## 配置

- **共享配置**：CLI 与 GUI 一致
- **导入导出**：配置文件
- **默认值**：开箱可用

## 集成

- **脚本调用**：CI 可用
- **日志**：结构化输出
- **退出码**：可判断结果

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
