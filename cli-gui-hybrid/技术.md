# CLI + GUI 混合工具 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 核心 | 纯逻辑模块 | 双入口复用 |
| CLI | commander / click | 参数与子命令 |
| GUI | Electron / Gradio / PySide | 图形界面 |
| 配置 | JSON / TOML | 共享配置 |
| 日志 | 结构化日志 | 过程可见 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **内核抽象**：逻辑与界面解耦
- **双入口**：CLI 与 GUI 共享同一核心
- **配置复用**：一处配置两处生效
- **进度反馈**：长任务可视化

## 学习路径

1. 先把核心逻辑抽成模块
2. 再包 CLI 入口
3. 最后加 GUI 入口
