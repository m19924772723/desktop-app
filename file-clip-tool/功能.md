# 文件管理与剪贴板工具 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 文件

- **批量操作**：重命名 / 移动
- **搜索**：名称与内容
- **预览**：快速查看

## 剪贴板

- **历史**：可搜索
- **分类**：文本 / 图片
- **快速粘贴**：热键

## 搜索

- **全文搜索**：内容检索
- **模糊匹配**：容错
- **筛选**：类型 / 时间

## 预览

- **文档预览**：免打开
- **图片预览**：缩略图
- **OCR 取字**：图片转文本

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
