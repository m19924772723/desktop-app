# Tauri 轻量桌面应用 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 框架 | Tauri 2 | Rust 后端 + Web 前端 |
| 语言 | Rust | 后端逻辑 |
| 前端 | React / Vue | 复用 Web |
| 打包 | tauri build | 极小安装包 |
| 权限 | Capabilities | 细粒度授权 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **架构**：Rust 核心 + 系统 WebView
- **命令调用**：invoke 与命令定义
- **权限模型**：Capabilities 白名单
- **体积优势**：不打包浏览器内核

## 学习路径

1. 先跑通 Tauri 示例
2. 再学 Rust 命令与前端调用
3. 最后打包分发
