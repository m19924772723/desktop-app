# Tauri 轻量桌面应用 · 简介

> 用 Tauri 打造体积小、内存低的桌面应用

## 能做什么

- 小体积桌面应用
- 系统调用与原生能力
- 安全沙箱与权限
- 多平台打包
- 低内存占用

## 适合的项目

- **轻量工具**：替代臃肿 Electron
- **系统集成工具**：原生能力
- **性能敏感桌面**：低占用

## 本机环境

- 本机状态：⚠️ 需补装 Rust
- 工具链：Tauri 2、Rust（需装）、前端框架、系统 WebView
- 注意：⚠️ 本机未装 Rust；装好 Rust 后即可开发，产物极小

## 快速开始

```bash
cargo install create-tauri-app
cargo create-tauri-app
npm run tauri dev
```
