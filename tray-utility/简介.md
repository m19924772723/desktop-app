# 托盘小工具与效率助手 · 简介

> 常驻系统托盘的效率小工具

## 能做什么

- 快捷启动与全局热键
- 剪贴板增强
- 截图工具
- 定时提醒
- 托盘菜单

## 适合的项目

- **效率助手**：常驻后台
- **快捷工具**：一键唤起
- **小软件**：轻量实用

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Node / Python / AutoHotkey（可选）、Electron / Tauri
- 注意：注意开机自启与资源占用；托盘应用要能优雅退出

## 快速开始

```bash
npm i electron
npx electron tray.js
# 托盘常驻，快捷键唤起
```
