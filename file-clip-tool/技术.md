# 文件管理与剪贴板工具 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 监听 | chokidar / fs.watch | 文件变化 |
| 存储 | SQLite | 索引与历史 |
| 搜索 | FTS5 / ripgrep | 快速检索 |
| 预览 | QuickLook 思路 | 免打开预览 |
| 压缩 | 7-Zip / tar | 归档 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **文件监听**：变化检测与去抖
- **索引**：路径与内容索引
- **剪贴板**：格式与历史
- **安全**：删除走回收站

## 学习路径

1. 先做目录监听
2. 再做搜索与剪贴板历史
3. 最后加批量操作与预览
