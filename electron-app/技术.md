# Electron 桌面应用 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 运行时 | Electron | Chromium + Node |
| 前端 | React / Vue | 复用 Web 技能 |
| 打包 | electron-builder | 安装包与绿色版 |
| 通信 | IPC | 主进程 ↔ 渲染进程 |
| 更新 | electron-updater | 自动更新 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **主进程与渲染进程**：职责分离
- **IPC 通信**：安全桥接（contextBridge）
- **安全加固**：nodeIntegration 关闭
- **打包**：多平台产物
