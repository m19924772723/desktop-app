# 托盘小工具与效率助手 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 宿主 | Electron / Tauri / Python | 托盘能力 |
| 热键 | GlobalShortcut | 全局快捷键 |
| 剪贴板 | Clipboard API | 历史与增强 |
| 截图 | desktopCapturer | 截屏 |
| 自启 | 开机启动项 | 随系统启动 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **托盘生命周期**：常驻与退出
- **全局热键**：注册与冲突
- **剪贴板**：监听与历史
- **资源占用**：空闲时低耗

## 学习路径

1. 先做一个托盘图标
2. 再加全局热键与菜单
3. 最后加实用功能
