# 笔记 / 知识管理桌面端 · 简介

> 本地优先的笔记与知识管理桌面端

## 能做什么

- Markdown 编辑与预览
- 双链与反向链接
- 全文检索
- 知识图谱
- 本地文件存储

## 适合的项目

- **个人知识库**：资料沉淀
- **笔记应用**：日常记录
- **文档管理**：本地优先

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Node / Electron、Markdown、SQLite、双链
- 注意：本机已有「文渊阁知识库」可作参考实现

## 快速开始

```bash
node server.mjs
# 打开本地知识库界面
node kb.mjs search "关键词"
```
