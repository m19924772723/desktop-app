# Tauri 轻量桌面应用 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 架构

- **极小体积**：几 MB 级
- **低内存**：复用系统 WebView
- **跨平台**：Win / macOS / Linux

## 能力

- **系统调用**：文件 / 进程
- **原生菜单**：托盘与快捷键
- **通知**：系统通知

## 打包

- **安装包**：msi / dmg / deb
- **签名**：代码签名
- **多平台**：交叉构建

## 安全

- **权限白名单**：Capabilities
- **沙箱**：隔离执行
- **通信校验**：命令参数

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
