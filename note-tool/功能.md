# 笔记 / 知识管理桌面端 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 编辑

- **Markdown**：编辑与预览
- **分栏**：边写边看
- **快捷键**：高效输入

## 组织

- **目录树**：层级管理
- **标签**：多维分类
- **双链 / 反链**：关联

## 检索

- **全文检索**：中文支持
- **命令面板**：快速跳转
- **标签云**：概览

## 同步

- **本地优先**：文件自持
- **版本历史**：快照
- **导出**：打包迁移

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
