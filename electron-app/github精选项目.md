# Electron 桌面应用 · GitHub 精选项目

> 以下为该方向值得参考的开源项目，星标为 2026-10 前后近似值，请以仓库当前页面为准。
> 「可借鉴」一栏说明读源码或使用时最值得学习的地方。

| 项目 | 星标 | 亮点 | 可借鉴 |
|---|---|---|---|
| [electron/electron](https://github.com/electron/electron) | 118k | 跨平台桌面框架 | 主渲染进程模型 |
| [tauri-apps/tauri](https://github.com/tauri-apps/tauri) | 110k | 轻量桌面框架 | 对比参考（体积优势） |
| [electron-userland/electron-builder](https://github.com/electron-userland/electron-builder) | 14k | 打包工具 | 多平台安装包 |

| [alex8088/electron-vite](https://github.com/alex8088/electron-vite) | 3k | Vite 集成 | 开发体验 |

## 使用建议

1. **先跑通再读码**：把项目跑起来，用一遍再回头看实现
2. **带着问题读**：聚焦「它怎么解决某个难点」，而不是逐行通读
3. **小步借鉴**：先抄一个模块的思路，再考虑整体架构
4. **注意许可**：商用前确认开源协议（MIT / Apache-2.0 / AGPL 差异很大）
