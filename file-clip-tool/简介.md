# 文件管理与剪贴板工具 · 简介

> 文件管理与剪贴板增强工具

## 能做什么

- 文件批量操作
- 快速搜索
- 剪贴板历史
- 截图 OCR 取字
- 快速预览

## 适合的项目

- **文件整理**：批量操作
- **素材管理**：检索定位
- **剪贴板工具**：内容复用

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Node / Electron、chokidar、SQLite、7-Zip（可选）
- 注意：文件监听注意性能；批量操作优先走回收站

## 快速开始

```bash
npm i chokidar better-sqlite3
node watch.js
# 监听目录变化并入库
```
